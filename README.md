### 稳定有两个前提：CPU 和 IP

第一个前提是 CPU 平均负载。搬瓦工的 CPU 限制机制是这样的：官方条款允许短时间跑满 100% CPU，但考核的是 **1 小时平均负载**，超过套餐上限后，系统会自动把 CPU 时钟频率压到规定水平，负载降下来之后 1 到 2 小时内自动解除，不会关停机器，也不会封号。触发限制时，KiwiVM 控制面板首页会出现一条提示，告诉你 CPU 正在被限速。

不同套餐的额度差很多。常规 KVM 20G 是单核的 50%，40G 是 75%，80G 起才是整核；CN2 GIA-E 20G 给到 100% 单核——注意购买页写的 2 核是峰值突发能力，平均限制按 1 核算，短时间跑满 2 核没问题，连续一小时平均超过 1 核才会触发。限量版套餐最严格，MINIBOX 只有单核的 20%，大部分限量版在 25%–30%。唯一不限 CPU 的是 SLA 企业级套餐，全核 24/7 无限制，但价格也贵一大截。
